



# Что такое Бинарное дерево поиска (BST)
BST (Binary Search Tree) — это бинарное дерево, где для каждого узла выполняется инвариант:
```text
Все элементы слева < узла < все элементы справа
```
Пример:
```text
        8
       / \
      3   10
     / \    \
    1   6    14
```


# Построение дерева
BST обычно строится последовательной вставкой элементов.

Алгоритм:
1) Первый/текущий элемент → root.
2) Для каждого следующего:
    * меньше → идём влево
    * больше → вправо
3) повтор 1 (пока с лева и с права не останется по null)


## Реализация (C#)
Узел дерева:
```cs
class Node{
    public int Value;

    public Node Left;
    public Node Right;

    public Node(int value){
        Value = value;
    }
}
```

# Вставка (Insert)
Идея: Рекурсивно ищем место, куда вставить.

```cs
Node Insert(Node root, int value){
    if (root == null)
        return new Node(value);
    
    if (value < root.Value)
        root.Left = Insert(root.Left, value);

    else if (value > root.Value)
        root.Right = Insert(root.Right, value);

    return root;
}
```

## Сложность
Средняя: **O(log n)**
Худшая (вырожденное дерево): **O(n)**


# Поиск
Идея: Сравниваем и идём в нужную сторону.

```cs
Node? Search(Node root, int value){
    if(root == null)
        return null;

    if (root.Value == value)
        return root;

    if (value < root.Value)
        return Search(root.Left, value);

    else
        return Search(root.Right, value);
}
```

## Сложность
Средняя: **O(log n)**
Худшая (вырожденное дерево): **O(n)**




# Удаление
тут 3 пути 

## Случай 1: Узел — лист
Меняем лист на null

## Случай 2: Один потомок
Заменяем узел его ребёнком:
```text
Хотим удалить 7

    5          5
     \   →     \
      7         8
       \
       8
```


## Случай 3: Два потомка
Алгоритм:
1) найти минимум в правом поддереве
```text
        8
       / \
      3   10
         /
        9

Удаляем 8, 9 минимум в правой части
```
2) Найденый минимум ставим на место удаляемого
```text
Заменяем 8 на 9 (8 будет уничтоена сборщиком муссора / программистом)

        8
       / \
      3   10
         /
        9
```
3) Если найденый минимум - не лист, то применить случай 2 (3 случай не может быть, так как иначе минимумом будет левая часть)





# Сбалансированное дерево
Высоты левого и правого поддеревьев отличаются не более чем на 1

## Алгоритм построения
Алгоритм:
0) Сортируем массив mid на возрастание
1) Берём середину (mid)
2) root = arr[mid]
3) Левое поддерево = левая часть массива
4) Правое = правая
