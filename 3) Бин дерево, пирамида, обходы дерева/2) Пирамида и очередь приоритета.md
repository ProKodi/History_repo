



# Что такое Heap
Heap — это полное бинарное дерево (complete tree), обычно реализованное на массиве, где выполняется свойство:

* Min-Heap
    * Родитель <= ребенку
* Max-Heap
    * Родитель >= ребенку

Пример (Min-Heap):
```text
        1
      /   \
     3     5
    / \   /
   7   9 8
```
Heap почти всегда хранится как массиве:
```text
Индекс:   0   1   2   3   4   5
Значения: 2   4   7   9   6   8

       2(0)
      /     \
    4(1)     7(2)
    / \       /
  9(3) 6(4)  8(5)

```


# Построение MinHeap (через Построение снизу (Последовательная вставка - убога))
```text
[9, 6, 8, 2, 4, 7] // n = 6

        9(0)
      /      \
    6(1)      8(2)
    /   \      /
   2(3) 4(4)  7(5)

1) Берём последний НЕ-листовой узел:
    индекс = n/2 - 1
    n = 6 → индекс = 2


2) Ищем элемент с индексом 2 и сравниваем его с детьми (берем минимум из них)
8(2) > 7(5)

3) Если родитель больше ребенка - меняем их местами

        9(0)
      /      \
    6(1)      7(2)
    /   \      /
  2(3) 4(4)  8(5)

После замены так же необходимо проверить ветвь где мы поменяли root


4) Если текущий индекс = 0 - останавливаем алгоритм
Иначе - Отнимаем от индекса 1 и повторяем шаг 2



индекс = 1

6(1) > 4(4)
6(1) > 2(3) 

Меняем местами 6(1) и 2(3) 

        9(0)
      /      \
    2(1)      7(2)
    /   \      /
  6(3) 4(4)  8(5)


индекс = 0

9(0) > 2(1)
9(0) > 7(2)
Меняем местами 9(0) и 2(1)

        2(0)
      /      \
    9(1)      7(2)
    /   \      /
  6(3) 4(4)  8(5)

индекс = 1 (проверка подветви)
9(1) > 6(3)
9(1) > 4(4)
Меняем местами 9(1) и 4(4)

        2(0)
      /      \
    4(1)      7(2)
    /   \      /
  6(3) 9(4)  8(5)

индекс = 3 (проверка подветви) - все в порядке
индекс = 4 (проверка подветви) - все в порядке

```
сложность: O(n)



# Операции (MinHeap)
## Вставка
```text
[2, 4, 7, 9]

        2
      /   \
     4     7
    /
   9

Добавляем 1

[2, 4, 7, 9, 1]

        2
      /   \
     4     7
    / \
   9   1

Далее нужно поднять вставленный элемент (добиваемся соблюдения условия MinHeap)

        2
      /   \
     1     7
    / \
   9   4

        1
      /   \
     2     7
    / \
   9   4

```
Сложность: O(log n)


## Удаление
### Лист
```text

        2

   9   6

хотим удалить 6

        2
      /   \
     4     7
    / 
   9

```

### Нода с одним потомком
```text

        2
      /   \
     4     7
    /
   9  

хотим удалить 4

        2
      /   \
     9     7

Мы убираем узел 4, а на его место ставим ео потомка - 9

```

# Очередь с приоритетом
Строится на Heap

Элементами данной очереди является следующее:
```text
зада + ее приоритет
```

Пример:
```text
[
  (A, 5)
  (B, 1)
  (C, 3)
]

     B(1)
    /    \
A(5)     C(3)

Порядок обработки:
B(1) (удаляем из кучи и перестраиваем кучу)

    C(3)
    /  
A(5)     

C(3) (удаляем из кучи и перестраиваем кучу)

A(5) 

A(5) (удаляем из кучи и перестраиваем кучу)


```
