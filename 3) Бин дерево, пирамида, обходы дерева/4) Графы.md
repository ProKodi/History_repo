



# Что такое граф
Граф — это структура, состоящая из:
* вершин (nodes, vertices) — объекты
* рёбер (edges) — связи между ними

Обозначается как:
```text
G=(V,E)
```
где: 
* V — множество вершин 
* E — множество рёбер

## Представление граффа в виде кода
```python
graph = {
    1: [2, 3],
    2: [1, 4],
    3: [1],
    4: [2]
}
```


# Виды графов
## По направлению
* Неориентированный граф — связи двусторонние (направление не важно)
* Ориентированный граф (digraph) — есть направление (A → B)



## По весам
* Невзвешенный - у ребер нет какого либо значения
* Взвешенный — у рёбер есть вес (например, расстояние)


## По структуре
* Простой граф — без петель и кратных рёбер
* Мультиграф — допускает несколько рёбер между вершинами
* Псевдограф — допускает петли


## Особые типы
* Полный граф — каждая вершина соединена со всеми
* Дерево — связный граф без циклов
* Цикл — замкнутый путь
* Двудольный граф — вершины делятся на 2 группы
* Планарный граф — можно нарисовать без пересечений


# Обходы для граффов
## Жертва
Знакомтесь, Петя - жертва для наших обходов
```text

    1
   /  \
  2    \
 /      \
4--------3

В виде словаря

graph = {
    1: [2, 3],
    2: [1, 4],
    3: [1, 4],
    4: [2, 3]
}

```

## Обход в ширину
При таком обходе будет трасировка будет следующей
```text
Шаг 1: 1
Шаг 2: 2, 3
шаг 3: 4
```
Принцип: сначала ближайшие, потом дальше

## Обход в глубину
При таком обходе будет трасировка будет следующей
```text
Шаг 1: 1
Шаг 2: 2
шаг 3: 4
шаг 4: 3
```
Принцип: сначала идем до упора, потом возращаемя на шаг назад

# Алгоритмы с графами
## Поиск в ширину
Сложность алгоритма = O(n) <br>
Данный алгоритм осуществляет поиск элемента по коллекции <br>

Поиск в ширину позволяет отвечать на вопроссы следующего типа:
1) Тип 1: Существует ли путь от точки А в точку В
2) Тип 2: Как выглядит кротчайший путь из точки А в точку В

Задача: 
    Предположим, вы находитесь в городе А и хотите добраться до города B. 
    Вы намереваетесь доехать на автобусе с минимальным количеством пересадок. 
    Возможные варианты: 
      С----F
     /   / | \  
    А   E  |  B
     \ /   |
      D----G

Решение: 
1) Составим мысленный графф

2) 1 шагом от точки А будут города {С, D}
    На этом этапе мы получим следующие пути:
    [
        [A, C],
        [A, D],
    ]

3) 2 шагом от точки А будут города {F, E, G}
    [
        [A, C, F],
        [A, D, E],
        [A, D, G],
    ]


    
4) 3 шагом от точки А будут города {B, G, E, F}
    [
        [A, C, F, B],
        [A, C, F, G],
        [A, C, F, E],

        [A, D, E, F],

        [A, D, G, F],
    ]


## Поиск по взвешенному графу
Сложность алгоритма = O(n^2)
Данный алгоритм вычисляет кратчайший путь во взвешенном графе. (Алгоритм диикстры)

Для того что бы алгоритм мог работать необходимо 
1) преставить коллекцию в виде оринтированнго взвешеного граффа
2) чтобы в этом графе отсутсвовали петли и циклы
3) чтобы имеелась начальная и конечная вершина
