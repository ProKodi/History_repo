



# Гари
Гари - дерево для обходов
```text
        A
      /   \
     B     C
    / \   / \
   D   E F   G
```

# Виды обхода дерева
## DFS (в глубину) — рекурсивная логика
Идея: идём максимально глубоко, потом возвращаемся

### Pre-order (прямой обход)
Сначала идем до упора влево, после на шаг вверх и в право и так по кругу 

Порядок:
```text
A → B → D

D → B
B → E

E → B
B → A

A → C → F

F → C
C → G

Итого:
A → B → D → E → C → F → G

```

### In-order (симметричный)
Left → Root → Right

Порядок: 
```text
D → B → E → A → F → C → G
```

### Post-order (обратный)
Left → Right → Root
Порядок:
```text
D → E → B → F → G → C → A
```


## BFS (обход в ширину)
по уровням слева направо

Порядок:
```text
A → B → C → D → E → F → G
```


## Кастомный
Эт решаете вы сами, какой будет обход у дерева
Очень хорошо для того использовать паттерн "Итератор"
