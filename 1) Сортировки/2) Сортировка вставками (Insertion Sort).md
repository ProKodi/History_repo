# Описание алгоритма по шагам
Данный алгоритм сортирует коллекцию по следующему принципу:
1) Считаем первый элемент уже отсортированным.
2) Берём следующий элемент массива.
3) Сравниваем его с элементами отсортированной части справа налево.
4) Сдвигаем все элементы, которые больше текущего, на одну позицию вправо.
5) Вставляем текущий элемент в освободившееся место.
6) Переходим к следующему элементу.
7) Повторяем процесс, пока не будет обработан весь массив.
   

## Оценка по сложности и по памяти
### Сложность: 
- Лучший случай (массив уже отсортирован): **O(n)**
- Средний случай/Худший случай (обратная сортировка): **O(n^2)**
  
### Затраты по памяти
**O(1)** 



# Пример визуализации алгоритма
## Исходный массив:
```
[8, 3, 5, 2]
```

## Шаг 1
Отсортированная часть:
```
[8] | 3 5 2
```

## Шаг 2
Вставляем `3`:
```
[3, 8] | 5 2
```

## Шаг 3
Вставляем `5`:
```
[3, 5, 8] | 2
```

## Шаг 4
Вставляем `2`:
```
[2, 3, 5, 8]
```



# Реализация в коде
## Python
```py
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1

        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1

        arr[j + 1] = key

    return arr


data = [8, 3, 5, 2]
print(insertion_sort(data))
```

## C#
```cs

class Program{
    static void InsertionSort(int[] arr){
        for (int i = 1; i < arr.Length; i++){
            int key = arr[i];
            int j = i - 1;

            while (j >= 0 && arr[j] > key){
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = key;
        }
    }

    static void Main(){
        int[] arr = { 8, 3, 5, 2 };

        InsertionSort(arr);

        Console.WriteLine(string.Join(", ", arr));
    }
}
```
