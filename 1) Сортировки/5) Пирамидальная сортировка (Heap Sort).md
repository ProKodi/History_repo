# Описание алгоритма по шагам
Пирамидальная сортировка (или сортировка кучей, HeapSort) — это метод сортировки сравнением, основанный на такой структуре данных как двоичная куча. <br>
Она похожа на сортировку выбором, где мы сначала ищем максимальный элемент и помещаем его в конец. <br>
Далее мы повторяем ту же операцию для оставшихся элементов.<br>
<br>
Двоичная куча — это законченное двоичное дерево, в котором элементы хранятся в особом порядке: 
значение в родительском узле больше (или меньше) значений в его двух дочерних узлах. 

Первый вариант называется max-heap, а второй — min-heap. <br>
Куча может быть представлена двоичным деревом или массивом.<br>


Поскольку двоичная куча — это законченное двоичное дерево, ее можно легко 
представить в виде массива, а представление на основе массива является 
эффективным с точки зрения расхода памяти. <br>
Если родительский узел хранится в индексе I то:
- левый дочерний элемент - 2 I + 1
- правый дочерний элемент — как 2 I + 2 
(при условии, что индексирование начинается с 0). <br>

Алгоритм пирамидальной сортировки в порядке по возрастанию:
1) Постройте max-heap из входных данных.
2) На данном этапе самый большой элемент хранится в корне кучи. <br>
    Замените его на последний элемент кучи, а затем уменьшите ее размер на 1. <br>
    Наконец, преобразуйте полученное дерево в max-heap с новым корнем.<br>
3) Повторяйте вышеуказанные шаги, пока размер кучи больше 1.


Процедура преобразования в кучу (далее процедура heapify) может быть применена 
к узлу, только если его дочерние узлы уже преобразованы. <br>
Таким образом, преобразование должно выполняться снизу вверх. <br>
Давайте разберемся с помощью примера: <br>

```

N // 2 = (int)2.5 = 2
```

## Оценка по сложности и по памяти
### Сложность: 
- Лучший/Средний случай: **O(n * log(n))**
  
### Затраты по памяти
- **O(1)**


# Реализация в коде
## Python
```py
def to_heap(col, n, i):
    """ Преобразование коллекции в бин кучу 
    i - индекс узла 
    """
    while True:
        # Делаем наибольший элемент коренем дерева
        max_item = i; 

        # Определяем ветки дерева и ищем среди них максимальное число 
        # Левая ветка корня (вычисляется по формуле 2*i + 1)
        l = 2 * i + 1; 

        # Если ветки выходят за предел массива (если левая ветвь выходит из массива, то правая тоже)
        # корень является листом дерева
        if (l >= n):  return

        # Правая ветка корня (вычисляется по формуле 2*i + 2)
        r = 2 * i + 2; 


        # Если левый дочерний элемент больше корня
        if (col[l] > col[max_item]):
            # Ссылаем корень на самый большой элемент
            max_item = l;


        # Если правый дочерний элемент больше, чем самый большой элемент на данный момент
        if ((r < n) and (col[r] > col[max_item])):
            # Ссылаем корень на самый большой элемент
            max_item = r;

        # Если самый большой элемент корень
        if (max_item == i): return

        # Если самый большой элемент не корень 
        # Рекурсивно преобразуем в двоичную кучу затронутое поддерево
        col[i], col[max_item] = col[max_item], col[i]
        i = max_item
    

def heap_sort(col):
    for i in range((len(col) // 2) - 1, -1, -1):
        to_heap(col, len(col), i)

    # Один за другим извлекаем элементы из кучи
    for i in range(len(col) - 1, -1, -1):
        # Перемещаем текущий корень в конец
        arr[0], arr[i] = arr[i], arr[0]
        
        # Востанавливаем структуру дерева на уменьшеной коллекции 
        to_heap(arr, i, 0);
    
    

# Обьявляем колекцию которую нужно отсортировать
arr = [4, 7, 2, 9, 7, 0, 1, 3, 6]; 
# Отправляем массив в функцию сортировки
heap_sort(arr);
print(arr)
```
