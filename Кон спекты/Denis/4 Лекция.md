# Сферы использования программных продуктов

## Основные сферы

1. Аппаратная часть компьютеров и сетей.

# Качество программного обеспечения (ISO 9126)

## Определение

Качество ПО — способность программы удовлетворять требованиям пользователей.

Стандарт ISO 9126 выделяет 6 основных характеристик качества.

---

# 1. Функциональность

Способность ПО решать нужные задачи.

### Атрибуты

* функциональная пригодность;
* точность;
* совместимость;
* соответствие стандартам;
* безопасность.

---

# 2. Надёжность

Стабильная работа программы в заданных условиях.

### Атрибуты

* зрелость;
* отказоустойчивость;
* восстановление после сбоев;
* соответствие стандартам надёжности.

---

# 3. Удобство использования (Usability)

Насколько ПО удобно пользователю.

### Атрибуты

* понятность;
* лёгкость обучения;
* удобство работы;
* привлекательность интерфейса.

---

# 4. Производительность (Efficiency)

Эффективность работы ПО относительно используемых ресурсов.

### Атрибуты

* скорость работы;
* эффективность использования памяти и ресурсов;
* соответствие стандартам производительности.

---

# 5. Удобство сопровождения (Maintainability)

Простота поддержки и изменения программы.

### Атрибуты

* анализируемость;
* лёгкость внесения изменений;
* стабильность;
* тестируемость.

---

# 6. Переносимость (Portability)

Способность работать в разных средах.

### Атрибуты

* адаптируемость;
* удобство установки;
* совместное существование с другим ПО;
* заменяемость.

---

# Метрики качества ПО

Примеры показателей:

* процент реализованных функций;
* корректность реализации;
* количество дефектов;
* полнота тестирования;
* качество документации.

# Жизненный цикл ПО (ISO/IEC 12207)

## Определение

ЖЦ ПО — процесс от идеи создания до вывода программы из эксплуатации.

---

# Группы процессов ЖЦ ПО

## 1. Основные процессы

Связаны напрямую с разработкой и использованием ПО.

### Включают:

* приобретение;
* поставку;
* разработку;
* эксплуатацию;
* сопровождение.

---

## 2. Вспомогательные процессы

Поддерживают качество и управление проектом.

### Включают:

* документирование;
* управление конфигурацией;
* обеспечение качества;
* верификацию;
* валидацию;
* аудит;
* решение проблем.

### Разница:

* **Верификация** — правильно ли создаётся продукт.
* **Валидация** — тот ли продукт создаётся.

---

## 3. Организационные процессы

Обеспечивают управление на уровне организации.

### Включают:

* управление проектом;
* создание инфраструктуры;
* улучшение процессов;
* обучение персонала.

---

# Особенности ISO/IEC 12207

* гибкость и адаптивность;
* не задаёт конкретные методы разработки;
* подходит для разных моделей ЖЦ;
* обеспечивает системный подход к разработке.

---

# Требования к ПО по ISO/IEC 12207

Стандарт учитывает:

* функциональность;
* интерфейсы;
* надёжность;
* безопасность;
* эргономику;
* БД;
* установку;
* пользовательскую документацию;
* сервисную поддержку.

---

# Ответственность участников проекта

Участники должны:

1. выбрать модель ЖЦ;
2. адаптировать процессы;
3. выбрать методы разработки;
4. выполнять задачи проекта.
