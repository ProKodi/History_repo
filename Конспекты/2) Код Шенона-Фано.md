# Алгоритм
Алгоритм построения кода Шенона фано:
1) Записываем мн-во символов в порядке убывания их вероятностей

2) Символы сообщения разбиваем на 2 п/группы с равными вероятностями
   1) Если не получится разделить на равные вероятности, то сумма нижней групы должна быть больше верхней

3) Для верхней группы присваиваем 1, для нижней - 0

4) Возвращаемся к 2 шагу пока в группе не останется 1 символ

# Определение эффективности 
## Коэфиицент статического сжатия 
Для определения коэффицента необходимо использовать следующую формулу:
$$ Kcc = Hmax / Lcp $$
Где:
* Hmax - максимальная энтропия
  * $$ Hmax = log(2, N) $$
  * log(2, N) - 2 логарифм от количества букв(N)


### Пример
| Символ | Вероятность | Код  | Размер кода |
| ------ | ----------- | ---- | ----------- |
| и      | 0.2         | 00   | 2           |
| н      | 0.1         | 010  | 3           |
| ф      | 0.1         | 0110 | 4           |
| о      | 0.1         | 0111 | 4           |
| р      | 0.1         | 100  | 3           |
| м      | 0.1         | 101  | 3           |
| а      | 0.1         | 110  | 3           |
| ц      | 0.1         | 1110 | 4           |
| я      | 0.1         | 1111 | 4           |

Общее количество букв (N) = 9

$$ Hmax = log(2, 9) = 3.17 $$

$$ Lcp = sum( 2, 3, 4, 4, 3, 3, 3, 4, 4 ) / 9 = 30 / 9 = 3.33 $$

$$ Kcc = 3.17 / 3.33 = 0.95 $$






## Коэффицент относительной эффективности 
Для определения коэффицента относительной эффективности необходимо использовать следующую формулу:
$$ Kоэ = H / Lcp $$
Где:
* H - Энтропия
  * $$ H = - sum{ pi * log(2, pi) } $$
  * pi - вероятность встретить букву
  * log(2, pi) - 2 логарифм от вероятности pi
  

### Пример
Данные теже что и тут [Коэфиицент статического сжатия](#коэфиицент-статического-сжатия)

$$ 
H = - sum{ 
    [ 0.2 * log(2, 0.2) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ] + 
    [ 0.1 * log(2, 0.1) ]
}
$$

$$ H = 3.1219280948873624 = 3.12 $$


$$ Kоэ = H / Lcp = 3.12 / 3.33 = 0.94 $$
